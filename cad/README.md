# CAD sources

**Design master:** `scoop.fs`, an Onshape FeatureScript custom feature ("Probe hood scoop system"). It lives in the Onshape document's "Probe scoop FeatureScript" tab and is inserted into the Part Studio "Scoop system (placed on scan site)"; the "Scoop FLAT" studio holds the same feature laid flat for export. `scoop.fs` is generated by `gen_fs.py` (which injects the fitted hood-site frame from `site_fit.json`); edit the generator, not the .fs.

**Local mirror:** `local_build.py` rebuilds every printable STL from the same parameters without Onshape (numpy, trimesh, shapely, manifold3d, networkx). Verified against the Onshape export of the same parameters to 0.13 mm. Use it when the Onshape API quota is exhausted or when you just want parts.

```bash
pip install numpy trimesh shapely manifold3d networkx scipy matplotlib pillow rtree
python3 cad/local_build.py                       # -> stl/
python3 cad/validate.py                          # -> validation/ (needs reference/scan)
python3 cad/make_figures.py stl docs/images      # -> figures for the docs
```

**Onshape automation** (needs `ONSHAPE_ACCESS_KEY` / `ONSHAPE_SECRET_KEY` in the environment; every call counts against the account's API quota):
- `push_scoop.py '{"roofTop": 76}'` regenerates `scoop.fs`, pushes it, re-inserts the feature with all parameters (JSON overrides optional) and prints regeneration status.
- `assemble_export.py` rebuilds the "Scoop on car" assembly from the scan meshes plus the design studio, refreshes the flat studio, and exports STL/STEP.
- `mesh_scale.fs` is the tiny feature used to fix STL imports that Onshape read in metres.
- `os_api.py` holds the document IDs and auth helpers; `onshape_state.json` the element IDs created so far.

**Scan analysis:** `site_fit.py` fits the hood curvature at the opening site from `reference/scan/02_hood_outer_mm.stl` and writes `site_fit.json`. `raster.py` is a small z-buffer renderer used by the figure and check scripts.
